⚙ 設定

Gemini API 金鑰（免費）

  1. 用 Google 帳號開啟 https://aistudio.google.com/apikey
  2. 按「Create API key／建立 API 金鑰」（第一次會自動建立專案），複製以 AIza 開頭的金鑰
  3. 貼到下面並按「儲存」。金鑰只存在這台電腦這個瀏覽器的 localStorage，不會上傳到 GitHub；只會直接送到 Google 的 API。
⚠ 免費方案的對話內容可能被 Google 用於改進產品；請勿輸入不想被保存的機密資料。
預設 gemini-3.8-flash（目前最新的 Flash，免費方案可用）。如果常遇到額度不足或想要反應更快，改用 gemini-3.5-flash-lite。
